## Mandatory Windows acceptance

1. On the owner's Windows repo, switch to this branch and `git pull --ff-only`. Keep a backup of the current personal clone.
2. Run `BUILD_PORTABLE.ps1` locally with the approved `CDM_Logo_Assets.zip` under Downloads. There must be no GitHub Actions.
3. Test generic EXE with no credentials and verify the updated About version 2.2.0 and all 14-language donation translations.
4. Close the personal clone; use the existing explicit clone-upgrade procedure. Never overwrite the personal clone blindly.
5. In the updated personal clone, inspect white-gutter removal, dark checkmarks, green identity under badge, sharp logo in Main and About, and each modal's red vector X.
6. Drag an unlocked card by its grip and by its body to another card in the **same section**, then to the append target; verify ordering survives closing/reopening. Verify locked-position cards don't move and action buttons never trigger a deploy on drag.
7. Test resize and Windows 100%/125%/150% DPI where available; license and support section must scroll and stay readable.
8. Only after acceptance, re-run `PACKAGE_RELEASE.ps1` to regenerate the blank generic EXE/ZIP/checksum. The pre-fix package is obsolete.
